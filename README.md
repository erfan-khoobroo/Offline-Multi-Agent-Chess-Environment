# Offline Multi-Agent Chess Environment

یک برنامهٔ آفلاین شطرنج با رابط گرافیکی Pygame برای بازی انسان با انسان، انسان با عامل، یا عامل با عامل.

## قابلیت‌های فعلی

- انتخاب بازیکن سفید و سیاه از میان انسان و چهار عامل راهبردی: تهاجمی، دفاعی، مهره‌محور و موقعیت‌محور.
- تصویر اصلی پروژه در سمت راست منوی شروع با برش متناسب با اندازهٔ صفحه نمایش داده می‌شود.
- نمایش صفحه و حرکت‌های قانونی، مدیریت نوبت‌ها و تشخیص پایان بازی با استفاده از `python-chess`.
- همهٔ عامل‌ها از Minimax با هرس آلفا–بتا و عمق دو نیم‌حرکت استفاده می‌کنند؛ بنابراین پاسخ مستقیم حریف را هم می‌سنجند.
- کیش‌ومات امتیاز قطعی دارد و برتری مادی و موقعیتی در ارزیابی صفحه لحاظ می‌شود. هر سبک معیار ویژه دارد: تهاجمی فشار اطراف شاه حریف را می‌سنجد؛ دفاعی امنیت شاه، سپر پیاده‌ای و مهره‌های بی‌دفاع را؛ مهره‌محور ارزش مادی و خطر ازدست‌دادن مهره‌ها را؛ موقعیت‌محور کنترل مرکز و فعالیت اسب‌ها و فیل‌ها را.
- عمق دو نیم‌حرکت به‌عنوان تنظیم پیش‌فرض، تعادلی ساده بین هوشمندی و سرعت ایجاد می‌کند.
- قانون سفارشی پروژه: اگر یکی از طرفین تنها با شاه بماند، پس از ۱۶ نیم‌حرکت مجموع بازی مساوی می‌شود. این قاعده جزو قوانین رسمی شطرنج نیست.
- حرکت آخر روی صفحه مشخص می‌شود و حرکت عامل‌ها با فاصله‌ای کوتاه نمایش داده می‌شود تا دنبال‌کردن بازی آسان‌تر باشد.

## نصب و اجرا

Python 3.10 یا جدیدتر را نصب کنید، سپس در پوشهٔ پروژه اجرا کنید:

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در ویندوز:

```powershell
.venv\Scripts\Activate.ps1
```

نصب وابستگی‌ها و اجرای برنامه:

```bash
python -m pip install -r requirements.txt
python main.py
```

## کنترل‌ها

- کلیک روی مهره و سپس خانهٔ مقصد: حرکت
- `R`: شروع دوبارهٔ بازی
- `M`: بازگشت به منوی اصلی
- `Esc`: خروج

## ساختار فایل‌ها

- `main.py`: رابط گرافیکی، ورودی کاربر، منو و حلقهٔ بازی.
- `chess_engine.py`: لایهٔ کمکی برای وضعیت صفحه، حرکت‌های قانونی و اجرای حرکت؛ قوانین را کتابخانهٔ `python-chess` فراهم می‌کند.
- `agents.py`: الگوریتم Minimax، هرس آلفا–بتا، تابع ارزیابی و چهار سبک عامل.
- `assets/`: تصاویر مهره‌ها.
- `fonts/`: قلم رابط کاربری.
